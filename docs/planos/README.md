# Planos

Planos, objetivos e ideias registrados com `/briefing` (prompt em
[12-briefing.md](../prompts/12-briefing.md)). São o contexto compartilhado entre você e a IA:
nas próximas conversas, aponte o arquivo em vez de repetir a história.

Nome do arquivo: `AAAA-MM-DD-<slug>.md` (data de criação).

## Modelo

```markdown
# <Título do plano>

- **Status:** rascunho | ativo | pausado | concluído | abandonado
- **Atualizado em:** AAAA-MM-DD

## Objetivo
O resultado que se quer, em 1–2 frases.

## Como saber que deu certo
Métricas ou critérios observáveis, com prazo.

## Contexto
O porquê, o que já foi tentado, situação atual.

## Restrições
Prazo, orçamento, tempo disponível, o que não pode mudar.

## Fatos × premissas
| Item | Tipo (fato/premissa) | Como validar |
| ---- | -------------------- | ------------ |

## Decisões
- AAAA-MM-DD — decisão — motivo.

## Perguntas abertas
1. ...

## Próximos passos
- [ ] passo — responsável — prazo

## Fora de escopo

## Histórico
- AAAA-MM-DD — criado.
```
