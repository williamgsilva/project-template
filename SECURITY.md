## Reportando uma vulnerabilidade

**Não abra issue pública.** Use o
[GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(aba *Security → Report a vulnerability*) ou envie e-mail para `{{SECURITY_CONTACT}}`.

Inclua: descrição, passos para reproduzir, impacto e versão afetada.

Prazos-alvo: confirmação em até **3 dias úteis**; correção de críticas em até **30 dias**.
